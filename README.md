## 📖 Overview

A drag-and-drop form builder — visually compose forms, configure fields, and export the schema.

## 🏗 Project structure

```
formbuilder/
├── src/
├── index.html
└── vite.config.ts
```

## 🛠 Tech stack

`React` · `TypeScript` · `Tailwind` · `Vite`

## 📦 Quick start

```bash
git clone https://github.com/m3rashid/formbuilder.git
cd formbuilder
pnpm install
pnpm dev
```
